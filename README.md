## ✨ Features

1. **🤪 Random Joke Machine**:
   - Automatically generates a funny kid-friendly joke on every page reload.
   - "Reveal Silly Punchline!" button with rimshot sound effect and confetti.
   - "🔀 Another Silly Joke" button.
   - "🗣️ Read Aloud" with funny cartoon voice via SpeechSynthesis API.
   - Category filters: Cousin Chaos, Food Fun, Animals, Knock-Knock, Sports, School.
   - Laugh counter (`😂 ROFL`) and interactive Cartoon Tomato thrower (`🍅 Splat!`).

2. **🧒 Custom Cartoon Avatars for Each Cousin**:
   - Scalable animated SVG avatars with personality props:
     - Aaditi's golden tiara and bossy smirk.
     - Tapasya's microphone, star glasses, and floating musical notes.
     - Devansh's safety goggles, cheeky grin, and floating LEGO brick.
     - Virat's backwards cap, cricket bat, and speed lines.
     - Ninad's ninja headband, chubby cheeks, and half-eaten cookie.
   - 3D Pixar avatar photo mode toggle.

3. **🎨 Interactive Silly Avatar Dress-Up Lab**:
   - Choose any cousin.
   - Try on silly hats: Pirate Captain, Party Cone, Alien Antenna, Chef Hat, Viking Horns.
   - Try on funny face props: Groucho Mustache, Red Clown Nose, Giant Bubblegum, Cool Shutter Shades.
   - "📸 Snap Photo" button with confetti celebration!

4. **🎲 "Who Is Most Likely To...?" Wheel / Spinner Game**:
   - Animated drumroll roulette that randomly picks a cousin for hilarious crimes (like eating all the cupcake frosting or building a hairdryer jetpack).

5. **📢 100% Kid Cartoon Soundboard**:
   - Self-contained Web Audio API synthesizer for instant zero-latency sound effects:
     - Whoopee cushion (fart sound)
     - Cartoon boing
     - Clown horn honk
     - Banana peel slip
     - Ba-dum-tss! (rimshot)
     - Magic sparkle
     - Silly giggle
     - Ta-Da fanfare

6. **📜 The Official Cousin Constitution**:
   - 5 hilarious house rules agreed upon by the cousins (and signed in cookie crumbs by Ninad).

7. **🎉 Disco Party Mode**:
   - Flashing neon party gradients, dancing wobbling cousin cards, and confetti cannons!

## 💻 Running Locally

Simply open `index.html` in any web browser, or run a local web server:

```bash
# Using Python
python3 -m http.server 3000

# Or using Node
npx serve .
```

Then visit `http://localhost:3000`.
